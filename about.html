About

mariosl35

Independent developer working mostly inside the FiveM/GTA ecosystem. I build resources, edit game assets, make graphics, and create tools around the work.

Background

What this is

mariosl35 started with FiveM resources and Lua scripts spread across local folders and unfinished repos. This site brings the work together and shows its real status: shipped, in progress, or shelved.

Most projects live in the FiveM and GTA space: HUDs, admin tools, handling edits, and texture editing. I also make general developer tools when a project needs one.

Working stack
  • Lua
  • FiveM Natives
  • NUI (HTML/CSS)
  • GIMP (image editing)
  • Blender (3D)
  • Content creation
  • Graphics modding
